# Painel do gestor — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a tela Painel do gestor (web e mobile) funcionando contra `GET /api/painel?periodo=7|30`, pixel perfect com o protótipo.

**Architecture:** as regras do Painel são funções puras em `apps/api/src/dominio/painel.ts` (TDD com o seed do protótipo, carregado em memória por `carregarDadosPrototipo`). O serviço lê o banco em três consultas enxutas e entrega ao domínio; a rota só valida o período. No gestor, a resposta vira linhas de apresentação em funções puras (`painel/apresentacao.ts`, `painel/formatos.ts`), e os componentes só desenham, copiando o CSS inline do protótipo.

**Tech Stack:** Hono + @hono/zod-openapi, Prisma 7, Vitest; Vue 3 + Vuetify + @tanstack/vue-query; harness visual Playwright + pixelmatch.

**Spec:** `docs/superpowers/specs/2026-09-29-telas-restantes-design.md` (seção "Painel (gestor)"), com o levantamento `docs/superpowers/specs/2026-09-29-telas-restantes/painel.md`.

## Global Constraints

- Pixel perfect: medidas, cores e textos saem do CSS inline de `docs/design/Acionamentos.dc.html` (linhas 65–151). `pnpm visual` com ≤ 0,2 % da região e ≤ 2 % do conteúdo; divergência se corrige no CSS, nunca no limite.
- `line-height: normal` (o `base.css` já força), sem margem de `h1`, padding padrão de botão `1px 6px` onde o protótipo não define.
- Fronts falam com a API só via `@kgb/api-client`. Nomes de domínio em português.
- "Hoje" sempre em `America/Sao_Paulo` (`dataSP` na API; formatos de `@kgb/ui` no front).
- Arredondamentos em TypeScript (`Math.round`); 82,5 min → "1h23", 122,5 min → "2h03", 12,5 % → "13%". A duração arredonda os minutos totais antes de dividir (nada de "1h60"); sem dados, "—".
- Fronteira de arquivos: `apps/api/src/rotas/painel.ts`, `apps/api/src/servicos/painel.ts`, `apps/api/src/dominio/painel.ts` (e testes), `apps/gestor/src/painel/**`, `tools/visual/casos-painel.ts`, este plano e os gerados do `pnpm api:generate`. Nada fora disso (nem `consultas.ts`, `saida.ts`, `@kgb/ui`, `api-client/src/index.ts`, `pnpm-lock.yaml`).
- Commits pequenos, em português, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Singular (decisão geral 1 do spec): "1 de 1 análise" (o protótipo escreve "análises").

## Review Focus

1. Painel sem nenhum dado no período (banco novo): KPIs "0%" / "0 de 0 análises" / "—" / "0% do período", barras só com tocos, Reprovações só com o título, Fila "Nada para conferir agora.", ranking com os ativos zerados ("—"). Teste no domínio (Task 1) e na apresentação (Task 3).
2. Prestador inativo com acionamento só **fora** do período, e prestador excluído com acionamento **no** período: o primeiro some do ranking, o segundo nunca entra, mas os acionamentos dele contam nos KPIs. Teste no domínio (Task 1).
3. Troca de período enquanto a nova consulta carrega: a tela mantém os números anteriores (sem zeros falsos nem piscar); erro da API vira o cartão com a mensagem. Teste na página (Task 4).
4. Sair da conta com 30 dias escolhido: o próximo login volta a 7 dias. Teste no estado (Task 4).
5. Tipo renomeado (duas grafias do `tipoNome` no período) e taxa acima de 100 %: duas linhas, "150% das demandas". Teste no domínio (Task 1) e na apresentação (Task 3).

### Task 1: Domínio do Painel (API, puro)

**Files:**
- Create: `apps/api/src/dominio/painel.ts`
- Test: `apps/api/src/dominio/painel.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type Periodo = 7 | 30
  export interface AcionamentoPainel { numero: number; data: string; status: StatusAcionamento; inviavel: boolean; prestadorId: string; iniciadoEm: Date | null; primeiroEnvioEm: Date | null; revisoes: readonly Decisao[]; tipos: readonly string[] }
  export interface PrestadorPainel { id: string; nome: string; cor: string; status: 'ativo' | 'inativo' }
  export interface PendentePainel { data: string; status: StatusAcionamento }
  export interface EntradaPainel { hoje: string; periodo: Periodo; pendentes: readonly PendentePainel[]; doPeriodo: readonly AcionamentoPainel[]; prestadores: readonly PrestadorPainel[] }
  export interface Painel { hoje; periodo; emAberto; paraHoje; aguardando; aprovacao: {aprovadas,total}; tempoMedioMin: number | null; inviaveis: {quantidade,totalPeriodo}; volume: {data,total,aprovados}[]; reprovacoesPorTipo: {tipoNome,reprovacoes,demandas}[]; ranking: {prestador:{id,nome,cor}; concluidos; revisoes:{aprovadas,total}; tempoMedioMin: number | null}[] }
  export function diasDoPeriodo(hoje: string, periodo: Periodo): string[]
  export function calcularPainel(e: EntradaPainel): Painel
  ```

Regras (vGestor, html:933–958): período = `data` entre hoje−(P−1) e hoje; `emAberto` = pendentes aberto/em_andamento/reprovado (qualquer data); `aguardando` idem; `paraHoje` = data === hoje e status ≠ aprovado; aprovação = revisões dos acionamentos do período; tempo médio = média de (1º envio − início) em minutos com fração, `null` sem dados; inviáveis = `inviavel` no período ÷ todos do período; volume = por dia, aprovados = aprovado e não inviável; reprovações = cada revisão reprovada soma 1 em cada demanda, agrupado por `tipoNome`, ordem n desc e desempate pela 1ª aparição (numero asc, ordem da demanda); ranking = prestadores recebidos (não excluídos, em ordem de cadastro) ativos sempre e inativos só com acionamento no período, ordem concluídos desc e taxa exata desc (sort estável).

- [ ] **Step 1: testes que falham**, em dois blocos:
  - regras unitárias com dados montados à mão: período de 7 e 30 dias (`diasDoPeriodo('2026-09-29', 7)` → `2026-09-23…2026-09-29`, virada de mês), ignora datas fora do período (futuro e antigo), volume com dia vazio, inviável aprovado fora de "aprovados", taxa de reprovação acima de 100 %, tipo renomeado em duas linhas, empate de reprovações pela primeira aparição, inativo sem atividade fora do ranking e com atividade dentro, desempate do ranking pela ordem recebida, painel vazio (`tempoMedioMin: null`, `aprovacao {0,0}`).
